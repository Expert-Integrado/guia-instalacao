Acesse claude.ai

Crie sua conta

Selecione o plano Pro

✅ Validação Você está pronto se: consegue entrar em claude.ai, fazer login, e o badge ao lado do seu nome mostra Pro.
Etapa 2·Gratuito

🛠️Preparar o Computador

Antes de instalar o Claude Desktop, instale duas ferramentas de apoio gratuitas: o Git e o Node.js. Leva cerca de 10 minutos e evita travas durante o evento.

💡
Por que preciso disso? O Claude Desktop (etapa 3) já vem com o Claude Code embutido — nada a instalar aí. Mas ele não instala o Git nem o Node.js: no Windows, a aba Code pede o Git na primeira vez que é aberta; e os aplicativos que você vai criar durante o evento geralmente precisam do Node.js para rodar no seu computador.

Como instalar

1. Instalar o Git

1
Acesse git-scm.com/downloads/win
git-scm.com/downloads/win. Baixe o instalador 64-bit para Windows (primeiro link da página).
2
Execute o instalador e avance em tudo
O instalador mostra muitas telas de opções — não mude nada, só clique em Next até o fim e depois em Install. As opções padrão são exatamente as que precisamos.
⚠️
A aba Code pediu o Git? Se o Claude Desktop já estava instalado e a aba Code mostrou um aviso pedindo o Git, é este passo que resolve. Instale, feche e abra o app de novo.

2. Instalar o Node.js

1
Acesse nodejs.org/pt/download
nodejs.org/pt/download. Ignore o bloco de comandos que aparece no topo da página — é instalação via Docker, você não precisa dele.
2
Desça até "Ou baixe uma versão pré-compilada"
Confira se o seletor mostra Windows e clique no botão verde Instalador Windows (.msi).
3
Execute o instalador
Abra o arquivo .msi baixado, aceite as opções padrão e clique em Next até o fim.

1. Ativar o Git (ferramentas de linha de comando)

No Mac o Git vem junto com as "ferramentas de linha de comando" da Apple. Só precisa ativar:

1
Abra o Terminal
Aperte Cmd + Espaço, digite Terminal e aperte Enter.
2
Digite o comando abaixo e aperte Enter
git --version
3
Siga conforme o que aparecer
Apareceu uma janela perguntando se quer instalar as ferramentas de linha de comando? Clique em Instalar, aceite os termos e aguarde (5–10 min). Apareceu um número de versão (ex.: git version 2.39)? Seu Mac já está pronto — pule para o Node.js.

2. Instalar o Node.js

1
Acesse nodejs.org/pt/download
nodejs.org/pt/download. Ignore o bloco de comandos que aparece no topo da página — é instalação via Docker, você não precisa dele.
2
Desça até "Ou baixe uma versão pré-compilada"
Troque o seletor para macOS e clique no botão verde Instalador macOS (.pkg).
3
Execute o instalador
Abra o arquivo .pkg baixado, aceite as opções padrão e conclua.
ℹ️
Precisa de conta no GitHub? Não. O Git é um programa que roda no seu computador. O GitHub é um site para publicar código na internet — são coisas diferentes, e nada no evento exige conta no GitHub.
ℹ️
✅ Validação Windows: o Git Bash aparece no menu Iniciar.
Mac: git --version no Terminal mostra um número de versão.
Ambos: node --version no terminal mostra a versão do Node, e a aba Code do Claude Desktop abre sem pedir nenhuma instalação.
Etapa 3·Gratuito

💻Claude Desktop

O Claude Desktop é o aplicativo oficial da Anthropic para Mac e Windows. Já vem com o Claude Code integrado em uma aba dedicada — você não precisa abrir terminal para nada.

💡
Esse é o caminho principal recomendado. Se você não programa, é por aqui que você vai.

Como instalar

1
Acesse claude.ai/download
claude.ai/download
2
Baixe a versão para macOS
3
Abra o arquivo .dmg baixado
4
Arraste o ícone do Claude para a pasta Aplicativos
5
Abra o app
1
Acesse claude.ai/download
claude.ai/download
2
Baixe a versão para Windows
3
Execute o instalador (.exe)
4
Siga as etapas e abra o app

Login com link de verificação

Quando abrir o app pela primeira vez, faça login com a mesma conta do Claude Pro.

⚠️
Atenção O Claude vai mandar um link de verificação no seu e-mail para validar o login. Abra o e-mail (do mesmo computador onde instalou o app) e clique no link. Sem isso, o login não conclui. Se não chegar em 1-2 minutos, confira a caixa de spam.
ℹ️
✅ Validação O app abre, você está logado, e vê três abas no topo: Chat, Cowork e Code.

Como contratar

1
Acesse o link de convite
lovable.dev
2
Clique em "Get started" / "Começar grátis"
3
Crie conta com Google ou e-mail
4
Ative o plano Pro
No painel, vá em Settings → Plans e ative o Pro.
ℹ️
✅ Validação Você consegue logar em lovable.dev, vê o painel principal com a opção de criar um novo projeto, e o seu plano mostra Pro nas configurações.
Etapa 5·Gratuito

🎙️Voice AI

Aplicativo da Expert Integrado para transcrição de voz com IA. Você aperta um atalho do teclado, fala, e o texto aparece colado direto onde seu cursor estiver — em qualquer programa do Windows.

💡
Quando a meta é digitar o mínimo possível, o Voice AI é a ferramenta que destrava isso.

Disponibilidade

  • Windows 10 e 11: disponível agora, gratuito
  • Mac: em breve. Veja alternativas no fim desta seção

Modos de transcrição

Para a maior parte dos casos, o modo Local é suficiente.

  • Local — roda no seu computador, offline. Gratuito. Recomendado para PCs com 8GB+ de RAM.
  • Online — usa a API da OpenAI (centavos por minuto). Precisa de chave de API e saldo na conta da OpenAI. Não sabe criar a chave? Siga o tutorial oficial da OpenAI.

Como instalar (Windows)

1
Acesse voiceai.expertintegrado.com.br
voiceai.expertintegrado.com.br
2
Clique em "Baixar Gratuitamente"
3
Preencha seus dados para liberar o download
4
Execute o instalador baixado
⚠️
Aviso azul do Windows? É normal Pode aparecer "O Windows protegeu o seu computador". Faça:
  1. Clique em Mais informações
  2. Vai aparecer Executar assim mesmo. Clique
  3. A instalação segue normalmente
O app é seguro — o aviso aparece porque ainda está em processo de certificação de assinatura digital. Se o antivírus pedir permissão, autorize.
ℹ️
✅ Validação O app está instalado, você configurou o atalho de teclado, e ao apertá-lo e falar, o texto aparece onde seu cursor está.

Alternativas para Mac

Até o Voice AI ficar disponível para Mac, contrate uma destas:

  • Wispr Flow — wisprflow.ai
  • Superwhisper — superwhisper.com
